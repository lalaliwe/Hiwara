## Default Permission

Default permissions for the mobile webview plugin

#### This default permission set includes the following:

- `allow-ping`
- `allow-create-webview`
- `allow-update-webview-bounds`
- `allow-destroy-webview`
- `allow-inject-script`
- `allow-inject-init-script`
- `allow-webview-go-back`
- `allow-webview-can-go-back`
